# Classroom of the Elite (Youkoso Jitsuryoku Shijou Shugi no Kyoushitsu e)

**Classroom of the Elite** is a Japanese psychological thriller light novel and anime series set at *Tokyo Metropolitan Advanced Nurturing High School*, an elite institution where students are ranked strictly by merit using the `S-System`.

> "All people are nothing but tools. It doesn't matter how it's done. It doesn't matter what needs to be sacrificed. In this world, winning is everything." — **Kiyotaka Ayanokoji**

---

## Class Hierarchy
The school divides first-year students into four classes based on perceived merit and defects:

1. **Class 1-A**: The highest-ranking honor students with elite academic and physical capabilities.
2. **Class 1-B**: Cooperative, high-performing students led by Honami Ichinose.
3. **Class 1-C**: Aggressive, power-driven students ruled by Kakeru Ryuen.
4. **Class 1-D**: The lowest class where students with hidden flaws or past issues are placed.

## Key Characters

| Character | Class | Role / Notable Trait |
| :--- | :--- | :--- |
| **Kiyotaka Ayanokoji** | Class 1-D | Mastermind from the *White Room* who manipulates events from the shadows. |
| **Suzune Horikita** | Class 1-D | Ice-cold perfectionist aiming to reach Class A. |
| **Kikyo Kushida** | Class 1-D | Popular, friendly idol on the surface with a manipulative dark side. |
| **Arisu Sakayanagi** | Class 1-A | Genius strategist and natural rival to Ayanokoji. |

---

### Why It Stands Out
* **Psychological Warfare**: Special exams test deception, betrayal, and social deduction rather than standard academics.
* **Unreliable Narrator**: Ayanokoji frequently conceals his true plans and abilities from both peers and the audience.
* **High Stakes**: Falling to `0` class points means losing monthly allowances, while expulsion is a constant threat.
